# 免費線上 QR Code 辨識器：圖片與相機掃描

辨識 PNG、JPEG、GIF、WebP 或 BMP 圖片中的 QR Code，也可使用相機。在瀏覽器本機解碼，先查看內容再開啟連結，無須上傳圖片。

[QR Code 辨識器](https://qrtools.luopeike.com/zh-Hant/qr-code-reader)

## 支援哪些 QR Code 圖片？

支援小於 20 MB、4000 萬像素的 PNG、JPEG、GIF、WebP 與 BMP 圖片。請保留完整清晰的碼與周圍留白。一次辨識一個碼，動畫圖片按靜止影格處理。

## 辨識後會自動開啟連結嗎？

不會。網站先以文字顯示內容，僅為 HTTP 或 HTTPS 網址提供可選的開啟連結按鈕。其他內容不會執行，也不會替你登入或連接 Wi-Fi。

## 相機掃描需要授權嗎？

這是選用功能，須在 HTTPS 網站授予瀏覽器相機權限，不請求麥克風。辨識成功、隱藏分頁、離開頁面或切回產生模式時，相機會停止。
