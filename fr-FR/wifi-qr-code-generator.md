# Générateur gratuit de QR Wi-Fi pour invités

Créez un QR Wi-Fi avec nom, mot de passe, WPA/WPA2/WPA3, WEP, réseau ouvert ou masqué. Export PNG/SVG sans envoi du mot de passe.

[Générateur de QR Wi-Fi](https://qrtools.luopeike.com/fr-FR/wifi-qr-code-generator)

## Comment un invité se connecte-t-il avec le QR Wi-Fi ?

Le code contient le nom, la sécurité, le mot de passe et, si choisi, l’indication de réseau masqué. Scannez avec un téléphone compatible puis confirmez la connexion. La compatibilité dépend du téléphone ; cet outil ne configure pas le routeur.

## Le mot de passe est-il chiffré dans le QR ?

Non. Toute personne disposant de l’image peut lire le mot de passe. Partagez un réseau invité uniquement avec les personnes autorisées. WPA à mot de passe, WEP et réseaux ouverts sont pris en charge, pas les comptes d’entreprise ni les certificats.

## Le QR change-t-il quand le mot de passe change ?

Non. Créez un nouveau QR avec les nouvelles données. L’ancienne image contient toujours l’ancien mot de passe.
