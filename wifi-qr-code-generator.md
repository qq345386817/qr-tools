# Free Wi-Fi QR Code Generator for Guests

Create a Wi-Fi QR code for guests: network name, password, WPA/WPA2/WPA3 or WEP, open and hidden networks. Download PNG or SVG with no password upload.

[Wi-Fi QR code generator](https://qrtools.luopeike.com/wifi-qr-code-generator)

## How does a Wi-Fi QR code connect a guest?

The code contains the network name, security type and password, plus a hidden-network flag if selected. Scan it with a compatible phone camera and confirm the connection. Device support varies; this tool does not configure the router.

## Is the Wi-Fi password encrypted in the QR code?

No. Anyone with the QR image can read its encoded password. Share a guest-network QR code only with people who should have access. The generator supports password-based WPA, WEP and open networks, not enterprise login or certificate profiles.

## What if I change my network password?

Generate a new Wi-Fi QR code using the new details. The old image does not update automatically and will still contain the old password.
