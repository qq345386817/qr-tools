# 免费在线二维码识别器：图片与相机扫描

从 PNG、JPEG、GIF、WebP 或 BMP 图片中识别二维码，也可使用相机扫描。浏览器本地解码，先查看内容再打开链接，图片无需上传。

[二维码识别器](https://qrtools.luopeike.com/zh-Hans/qr-code-reader)

## 支持识别哪些二维码图片？

支持小于 20 MB、4000 万像素的 PNG、JPEG、GIF、WebP 和 BMP 图片。请使用完整、清晰且保留周围留白的二维码图片。一次识别一个二维码，动画图片按静止帧处理。

## 识别二维码会自动打开链接吗？

不会。网站先以文本显示内容，仅为 HTTP 或 HTTPS 地址提供可选的打开链接按钮。其他内容不会被执行，识别也不会替你登录账号或连接 Wi-Fi。

## 相机扫描需要授权吗？

相机扫描是可选功能，需要在 HTTPS 网站上授予浏览器相机权限，不请求麦克风权限。识别成功、隐藏标签页、离开页面或切回生成功能时，相机会停止。
