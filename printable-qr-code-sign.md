# Printable Wi-Fi, Event & Menu QR Code Signs

Create printable guest Wi-Fi QR signs, event entry cards and menu-link signs. Add a title and note, save PNG or print to PDF without an account.

[Printable Wi-Fi, Event & Menu QR Code Signs](https://qrtools.luopeike.com/printable-qr-code-sign)

## What does this tool create?

Create printable guest Wi-Fi QR signs, event entry cards and menu-link signs. Add a title and note, save PNG or print to PDF without an account.

## Is my input uploaded or saved?

No. Input and output are processed in this browser, without an account or persistent history. Downloaded files contain the data you entered.

## What are the limitations?

Signs contain static QR data. Replace the sign when the Wi-Fi password or link changes. Anyone with a Wi-Fi QR can read its password.
