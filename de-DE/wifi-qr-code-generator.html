Fragen zu QR-Codes

Wie verbindet sich ein Gast mit dem WLAN-QR-Code?

Der Code enthält Netzwerkname, Sicherheit, Passwort und bei Auswahl die Kennzeichnung als verborgenes Netzwerk. Mit einem kompatiblen Handy scannen und die Verbindung bestätigen. Die Unterstützung hängt vom Gerät ab; das Tool konfiguriert keinen Router.

Ist das WLAN-Passwort im QR-Code verschlüsselt?

Nein. Jeder mit dem QR-Bild kann das Passwort auslesen. Teile ein Gastnetzwerk nur mit berechtigten Personen. Unterstützt werden passwortbasiertes WPA, WEP und offene Netze, keine Unternehmensanmeldung oder Zertifikatprofile.

Aktualisiert sich der Code bei Passwortänderung?

Nein. Erstelle mit den neuen Daten einen neuen Code. Das alte Bild enthält weiterhin das alte Passwort.
