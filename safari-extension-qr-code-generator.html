Safari QR extension

Safari extension QR code generator for iPhone, iPad, and Mac

QR Tools adds a simple QR action to Safari. Open it from the toolbar and the current tab is ready to scan on another device.

Built for Safari users

Use QR Tools on iPhone, iPad, and Mac through the App Store. It also includes a native QR generator for common content types when you are not using the browser extension.

Extension features

Current tab QR

Automatically starts from the active Safari tab, with editable QR content before you share.

Copy or save

Copy the QR image to the clipboard or save it as a PNG for slides, documents, and support notes.

Chrome companion included

If you also use Chrome, QR Tools has a Chrome Web Store version for the same current-tab QR workflow.

Install the Safari extension

Install QR Tools from the App Store, then enable the extension from Safari settings.
