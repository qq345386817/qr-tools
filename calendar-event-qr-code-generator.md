# Calendar Event QR Code Generator & ICS Download

Create a single-event Google Calendar link QR and download an ICS file for compatible calendars. Set start, end and time zone; no hosted event storage.

[Calendar Event QR Code Generator & ICS Download](https://qrtools.luopeike.com/calendar-event-qr-code-generator)

## What does this tool create?

Create a single-event Google Calendar link QR and download an ICS file for compatible calendars. Set start, end and time zone; no hosted event storage.

## Is my input uploaded or saved?

No. Input and output are processed in this browser, without an account or persistent history. Downloaded files contain the data you entered.

## What are the limitations?

The QR opens a Google Calendar event template, not an already saved event. ICS downloads can be imported into compatible calendars. Time-zone and DST checks do not replace a trial import.
