Chrome Help

Use the Chrome extension

Open the page you want to share, then open QR Tools from the Chrome toolbar. The current tab URL appears automatically and can be edited before export.

Export QR images

Use Copy QR or Save PNG when you need to reuse the QR code in a document, presentation, or message.

Use QR Tools on iPhone or iPad

Chrome on iPhone and iPad does not support Chrome extensions. Install the App Store version and use QR Tools in Safari instead.
