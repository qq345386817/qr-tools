# Free Online QR Code Reader for Images & Camera

Read QR codes from PNG, JPEG, GIF, WebP or BMP images, or use your camera. Decode locally, review the text and open links yourself. No image upload.

[QR code reader](https://qrtools.luopeike.com/qr-code-reader)

## Which QR images can I read?

Choose a PNG, JPEG, GIF, WebP or BMP image below 20 MB and 40 megapixels. Use a clear image with the entire code and its light margin visible. The reader finds one QR code at a time; animated images are read as a still frame.

## Will scanning automatically open a link?

No. The decoded content is shown as text first. Only HTTP and HTTPS addresses receive an optional Open link button. Other content is not executed, and scanning does not sign you in or join a Wi-Fi network.

## Does camera scanning need permission?

Camera scanning is optional and requires browser permission on HTTPS. Audio is not requested. Camera tracks stop when a code is found, the tab is hidden, you leave the page or switch back to Create.
